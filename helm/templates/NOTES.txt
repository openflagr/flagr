1. Port-forward the primary Service (UI / CRUD):

   kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "flagr.fullname" . }} 18000:{{ .Values.service.port }}

2. Check health:

   curl -sS http://127.0.0.1:18000{{ .Values.test.path }}

3. Configure Flagr with env / envFrom (every FLAGR_* key):

   https://openflagr.github.io/flagr/flagr_env

   Scaling (https://openflagr.github.io/flagr/flagr_self_host#kubernetes-scaling):
{{- if .Values.gitops.enabled }}

   GitOps is on: every pod is json_http eval-only (read-only UI). Scale replicaCount.
   Flags URL: {{ .Values.gitops.flagsURL | default "(FLAGR_DB_DBCONNECTIONSTR via env)" }}
{{- else }}

   - SQLite (default): keep replicaCount=1 (one writer). Persist with extraVolumes
     named "data". For more eval QPS set evalReplicas.replicaCount; those pods are
     eval-only json_http readers of this primary.
{{- if gt (int .Values.evalReplicas.replicaCount) 0 }}

   Eval replicas are enabled ({{ .Values.evalReplicas.replicaCount }}).
   UI / flag writes → svc/{{ include "flagr.fullname" . }}
   Evaluation SDKs   → svc/{{ include "flagr.evalFullname" . }}
   Flags URL         → {{ include "flagr.evalFlagsURL" . }}
{{- end }}

   - GitOps: gitops.enabled + gitops.flagsURL (GitHub raw). All pods json_http;
     scale replicaCount. Leave evalReplicas at 0.

   - MySQL / Postgres: raise replicaCount; leave evalReplicas at 0. Every pod
     shares the database.
{{- end }}

   Add your own Ingress / HPA / NetworkPolicy.

   Chart vs process defaults: FLAGR_PPROF_ENABLED=false, FLAGR_DB_DBCONNECTION_DEBUG=false,
   FLAGR_LOGRUS_FORMAT=json. Re-enable pprof via env if you need it.

   If you set FLAGR_WEB_PREFIX, also override livenessProbe/readinessProbe httpGet.path,
   test.path, and evalReplicas.flagsURL (JWT/basic whitelist paths must include the prefix).
